/skill-creator 코딩 에이전트(Claude Code, Codex)의 한국어 답변이 이상해서 교정에 시간과 토큰을 다 쓰고 실제 작업을 못 하는 문제를 고치는 온보딩 스킬을 만들어줘. 처음 한 번만 실행하면 영구적으로 적용되게 하고 싶어.

증상은 이런 것들이야. 코딩하는데 회계 쪽 단어를 가져오거나, 번역투, 영어식 비유, 억지 순우리말이 심각함:

축, 갈래, 행, 접다, 가르다, 재다, 잣대, 훑다, 소속, 몫, 원장, 사본, 두 벌 ...

요구사항:

1. 스킬을 매번 부르는 방식이 아니라, 에이전트가 세션 시작마다 자동으로 읽는 파일에 규칙을 심는 방식일 것
   - Claude Code: ~/.claude/CLAUDE.md (전역), <repo>/CLAUDE.md (프로젝트)
   - Codex: ~/.codex/AGENTS.md (전역), <repo>/AGENTS.md (프로젝트)
   - 여러 번 실행해도 중복되지 않게 마커로 감싸고, 기존 내용은 보존, 처음 수정 시 .bak
2. 금지어와 대체어를 데이터 파일로 분리해서 팀이 규칙을 추가하거나 끌 수 있게 할 것
   - 맥락에 따라 맞을 수 있는 단어(행=테이블 row, 축=그래프 axis, 몫=나눗셈, 접기=UI collapse)는 error가 아니라 warn
   - 정규식은 다른 단어 안의 글자를 잡지 않아야 함 (실행, 은행, 구축, 존재, 접근...)
3. 답변 초안을 검사하는 파이선 스크립트
   - stdlib only, 코드 블록과 인라인 코드는 검사 제외
   - --fix는 1:1 대응이 확실한 것만 자동 치환
   - --json, --list-terms, 종료 코드로 CI 연동 가능
4. 용어 외에 근거(경로:줄 표기)와 확신도(확인함/추정/모름) 규칙도 함께

폴더 구조는 이 저장소의 다른 스킬과 동일하게 SKILL.md + CREATION_PROMPT.md +
scripts/ + references/ 로.
